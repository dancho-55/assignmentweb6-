# Подготовка к защите — Assignment 6

## Как устроена работа

В проекте пять HTML-страниц, по одной на каждую часть задания. На каждой странице есть navbar. Оформление находится в style.css, а логика каждой части — в отдельном JS-файле. jQuery подключается через CDN перед моим скриптом.

## Что показать преподавателю

0. Открыть консоль: сообщение «jQuery is ready!». $(document).ready(function () { ... }) запускает код после готовности структуры страницы.
1. Нажать Change content and styles. #idText — селектор ID, .classText — класса, li — тега. text() вставляет обычный текст, html() позволяет вставить HTML-разметку, css() меняет стиль.
2. Hide скрывает абзац, Show показывает, Toggle переключает видимость.
3. Fade Out постепенно скрывает изображение через прозрачность. Fade In возвращает, Fade Toggle переключает.
4. Slide Up закрывает панель, Slide Down открывает, Slide Toggle переключает.
5. Add Item (end) добавляет li в конец списка методом append(). Кнопка start использует prepend(). Remove удаляет последний li методом remove(). Счётчик увеличивается, чтобы новые пункты отличались.
6. attr() читает или изменяет атрибут. Для картинки меняется src и alt, для ссылки — href и текст.
7. Событие input срабатывает при вводе, вставке и удалении текста. val() получает значение поля. text() выводит его в span. $(this) означает поле, в котором сейчас происходит событие.
8. animate() меняет left, width и height. У квадрата position: relative, поэтому left и top сдвигают его относительно исходного места.
9. Несколько animate() идут по очереди: вправо, вниз, уменьшение и возврат. jQuery ставит их в очередь.
10. Один animate() меняет положение, размер и прозрачность одновременно. opacity: 0.4 означает 40% непрозрачности.
11. Аккордеон: next() находит ответ сразу после кнопки. not() исключает текущий ответ при закрытии других. slideDown()/slideUp() открывают и закрывают его. aria-expanded сообщает состояние кнопки вспомогательным технологиям.

## Возможные вопросы

- Зачем ready? Чтобы элементы уже существовали в DOM перед назначением обработчиков.
- Чем jQuery отличается от JavaScript? Это библиотека на JavaScript, которая даёт удобные методы.
- Почему размер задан без px в animate()? Для width, height, left и top jQuery использует пиксели по умолчанию.
- Что значит 600? Длительность эффекта в миллисекундах.
- Зачем stop(true, true)? Остановить текущий эффект, очистить очередь и завершить текущий переход. Это помогает при частых кликах.
- Почему для квадратов stop(true, false)? Очищается очередь, но текущий переход не прыгает в конечное состояние; затем код задаёт исходные значения.
- Что делает Reset? Останавливает анимацию и возвращает исходные CSS-свойства.
- Почему text(), а не html() для формы? Введённое пользователем должно отображаться обычным текстом, даже если содержит HTML-теги.
- Куда исчезают добавленные пункты после обновления? Они хранятся только в текущей странице, без базы данных и localStorage.
